# This repository

This tree is a set of instruction folders rather than an application, so pick one and work from there.

- Conversation: `conversation/AGENTS.md` and `shared/base.md`
- Coding: `coding/AGENTS.md` and `shared/base.md`
- Research: `research/AGENTS.md` and `shared/base.md`
- Writing: `writing/AGENTS.md` and `shared/base.md`

If the current message is mixed, use the folder for the deliverable they asked for (code goes to coding, a sourced brief goes to research, a draft goes to writing, and everything else goes to conversation).
